# Breadcrumb

## Overview

Hierarchical wayfinding for nested routes. Renders an ordered list of links
with chevron or slash separators.

## Import

<Source
  language="tsx"
  code={`import { Breadcrumb } from "@/components/ui/breadcrumb";`}
/>

## Default

<Canvas of={BreadcrumbStories.Default} />

## Slash separator

Pass `separator="slash"` to swap the chevrons for slashes. Use when the
trail represents a path-like hierarchy (folders, document trees) where
slashes read more naturally.

<Canvas of={BreadcrumbStories.SlashSeparator} />

## Accessibility

- Renders inside `<nav aria-label="Breadcrumb">`.
- The final crumb is marked `aria-current="page"` so screen readers
  announce it as the current location.
- Each link has a `--touch-target-compact` (40 px) hit area for
  comfortable touch use.
