# Calendar

## Overview

Inline calendar built on `react-day-picker`. Two variants: `single`
(pick one date) and `multi` (pick N dates with optional min/max
selection counts). Values are ISO `YYYY-MM-DD` strings. Use the bare
`Calendar` for inline pickers (sidebars, settings panels); for a
text-entry field with a calendar popover, reach for `DateInput`.

## Variants

### Bordered

Wrap the calendar in the LifeSG-style bordered chrome — a 1 px border with
8 px corner radius. Use when the calendar is the primary element on the
surface and benefits from a visual frame.

<Canvas of={CalendarStories.Bordered} />

### Multi-select

`variant="multi"` switches from `value` / `onChange` (single ISO date) to
`values` / `onChange` (array of ISO dates). Useful for "pick all the days
you're free" / availability-style flows.

<Canvas of={CalendarStories.Multi} />

### Multi-select with limits

Pass `minSelectable` and `maxSelectable` to cap the number of dates. The
picker silently rejects out-of-bounds selections — pair with a visible
helper text if your UX needs to surface the limit.

<Canvas of={CalendarStories.MultiWithLimit} />

## Constraints

### With min / max date

`minDate` and `maxDate` clamp the picker's allowed window. Days outside
the window are visually disabled and unselectable.

<Canvas of={CalendarStories.WithMinMax} />

### With disabled dates

Pass an array of ISO strings to `disabledDates` to mark specific days as
unselectable while keeping the rest of the month available. Disabled days
are skipped by keyboard navigation.

<Canvas of={CalendarStories.WithDisabledDates} />

## Accessibility

- Day buttons are real `<button>`s. `react-day-picker` wires
  arrow-key navigation between days and tab into the caption / nav
  buttons.
- Disabled days are skipped by keyboard navigation and not
  clickable; today is marked with a small dot indicator.
- Caption / month / year selects are native `<select>` overlays
  (`captionLayout="dropdown"`) so screen readers expose them as
  combobox controls.

## Notes

- All values are ISO `YYYY-MM-DD` strings — internal conversion to
  `Date` objects is hidden from callers.
- `disabledDates` accepts plain ISO strings; `minDate` / `maxDate`
  configure the picker's allowed window. They compose (a date may be
  disabled via either rule).
- Multi-variant respects `minSelectable` / `maxSelectable` — selections
  outside the bounds are silently rejected. Pair with a visible
  hint if your UX needs to surface the bounds.
- Token namespaces: `--calendar-bg`, `--calendar-text`,
  `--calendar-bg-hover`, `--calendar-bg-selected`,
  `--calendar-text-selected`, `--calendar-text-today`,
  `--calendar-text-disabled`, `--calendar-ring-focus`,
  `--calendar-min-width`.
- For text-entry with a popover calendar, use `DateInput`. For range
  selection, use `DateRangeInput`. Use the bare `Calendar` for inline
  pickers (sidebars, settings panels).
