# Drawer

## Overview

Side-anchored panel built on Base UI's `Dialog`. Slides in from any of
four sides, supports header + body + footer slots, and ships with a
built-in close button (can be hidden for custom chrome).

## Import

<Source
  language="tsx"
  code={`import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerHeader,
  DrawerBody,
  DrawerFooter,
  DrawerTitle,
  DrawerClose,
} from "@/components/ui/drawer";

<Drawer>
  <DrawerTrigger render={<Button>Open</Button>} />
  <DrawerContent side="right">
    <DrawerHeader><DrawerTitle>Title</DrawerTitle></DrawerHeader>
    <DrawerBody>…</DrawerBody>
    <DrawerFooter>…</DrawerFooter>
  </DrawerContent>
</Drawer>`}
/>

## Sides

### Right (default)

`side="right"` is the default — the conventional placement for filters,
detail panes, and settings panels.

<Canvas of={DrawerStories.Default} />

### Left

`side="left"` suits navigation-style drawers that mirror a left-hand
menu or tree.

<Canvas of={DrawerStories.Left} />

### Top

`side="top"` spans the full viewport width and slides down — useful for
notification or announcement panels.

<Canvas of={DrawerStories.Top} />

### Bottom

`side="bottom"` slides up from the bottom edge — the natural choice for
mobile sheet-style interactions.

<Canvas of={DrawerStories.Bottom} />

## Composition variants

### Hidden close button

`hideClose` removes the built-in X. Use when you supply your own
dismiss affordance (e.g. a Cancel button in the footer via
`DrawerClose`) and don't want duplicate close controls.

<Canvas of={DrawerStories.HideClose} />

### Body only

Header and Footer slots are optional — a bare `DrawerBody` works for
simple content panes that don't need a title bar or action row.

<Canvas of={DrawerStories.BodyOnly} />

## Triggered

Wrap any clickable element in `DrawerTrigger` to open the drawer on
click instead of controlling `open` yourself.

<Canvas of={DrawerStories.TriggeredByButton} />

## Accessibility

- Base UI's `Dialog` handles focus trapping, focus restoration, and Esc
  to close. Tab cycles inside the drawer until it's dismissed.
- `DrawerTitle` should always be present (even when visually styled) —
  Base UI wires it to `aria-labelledby` on the popup.
- `aria-label="Close"` on the X button is built in; no extra plumbing
  required.
- Backdrop blocks pointer events on the rest of the page while the
  drawer is open.

## Notes

- Token namespaces: `--drawer-width-side`, `--drawer-height-side`,
  `--drawer-bg`, `--drawer-overlay`, `--drawer-shadow`.
- The side prop only affects slide direction + dimensions; the same
  Header / Body / Footer composition works for all four sides.
- For dropdown-style overlays (no full-screen backdrop), use
  `popover` or `menu` instead.
- `DrawerClose` is a render-prop wrapper — pass it any clickable
  element via `render={…}` to close the drawer on click.
