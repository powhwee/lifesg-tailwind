# Avatar

## Overview

Circular identity indicator. Renders a single initial from a string
child (LifeSG's first-character rule) or an arbitrary node (image, icon).
Two sizes: `default` and `small`.

## Import

<Source
  language="tsx"
  code={`import { Avatar } from "@/components/ui/avatar";

<Avatar>Jane Doe</Avatar>             // initial "J"
<Avatar><img src="…" alt="…" /></Avatar>
<Avatar sizeType="small">M</Avatar>`}
/>

## Variants

### Small

`sizeType="small"` for dense chrome — list rows, comment threads,
compact headers — where the default size would crowd the layout.

<Canvas of={AvatarStories.Small} />

### With image

Pass an `<img>` child for a profile photo; size it with
`size-full object-cover` so it fills the circle. Remember a meaningful
`alt` — the wrapper does not supply one.

<Canvas of={AvatarStories.WithImage} />

### With icon

Pass an icon node for anonymous or placeholder users — e.g. a generic
person glyph before the user has set a photo. Mark the icon
`aria-hidden` since it's decorative.

<Canvas of={AvatarStories.WithIcon} />

### Initials gallery

String children render only their first character (LifeSG's
first-character rule) — pass the full name and the component trims it.

## Accessibility

- The avatar itself is decorative — pair it with the user's name in
  adjacent text so screen readers announce who it represents.
- When passing an `<img>`, set a meaningful `alt` (the username) rather
  than leaving it empty; the avatar wrapper does not provide one.
- Decorative icons inside the avatar should set `aria-hidden`.

## Notes

- Token namespace: `--avatar-bg`, `--avatar-text`,
  `--avatar-size-default`, `--avatar-size-small`, plus matching font
  tokens. Adjust globally via the token; do not override `size-` /
  `bg-` per call unless intentionally going off-system.
- The first-character-only rule for string children matches LifeSG's
  React Design System; pass full text and the component will trim. For
  multi-initial avatars (e.g. "JD"), pass the literal "JD" as a child
  via a fragment or just a longer string.
