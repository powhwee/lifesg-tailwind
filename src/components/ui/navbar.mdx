# Navbar

## Overview

Site-level top navigation: brand on the left, primary nav items in the
middle, action buttons (Log in / Sign up) on the right. Collapses to a
hamburger-triggered Drawer on mobile.

## Import

<Source
  language="tsx"
  code={`import { Navbar } from "@/components/ui/navbar";

<Navbar
  brand={{ brandName: "LifeSG", logoSrc: "/logo.svg" }}
  items={[
    { id: "home", label: "Home", href: "/" },
    { id: "services", label: "Services", href: "/services" },
  ]}
  selectedId="services"
  actions={[
    { id: "login", label: "Log in", variant: "outline" },
    { id: "signup", label: "Sign up" },
  ]}
  masthead
/>`}
/>

## Variants

### With selected item

Pass `selectedId` to mark the current page's nav item. The selected item
gets `aria-current="page"` and the bottom-bar indicator, so users always
know where they are in the site.

<Canvas of={NavbarStories.WithSelected} />

### With actions

`actions` renders buttons on the right edge (e.g. Log in / Sign up). Each
action takes an optional `variant` to demote the secondary action to an
outline button. On narrow shells the actions move into the mobile drawer
footer automatically.

<Canvas of={NavbarStories.WithActions} />

### With masthead

Set `masthead` to render the standard "A Singapore Government Agency
Website" strip above the bar. Use for any public-facing government
service page.

<Canvas of={NavbarStories.WithMasthead} />

### Full chrome

Everything together — masthead, selected item, and action buttons. This
is the typical configuration for a production service shell.

<Canvas of={NavbarStories.FullChrome} />

## Accessibility

- Brand link uses `aria-label={brandName}` so screen readers know what
  the logo links to.
- Primary nav is wrapped in `<nav aria-label="Primary">`. Mobile drawer
  nav is wrapped in `<nav aria-label="Primary mobile">` to disambiguate.
- The selected item carries `aria-current="page"` plus a visual
  bottom-bar indicator (`--navbar-indicator` token).
- Mobile menu trigger uses `aria-expanded` reflecting the drawer state.

## Notes

- Token namespaces: `--navbar-bg`, `--navbar-text`, `--navbar-border`,
  `--navbar-bg-hover`, `--navbar-indicator`.
- The hamburger menu shows at `<= md`; primary nav inline shows at
  `md+`. Action buttons inline at `@4xl+` (container query) — narrower
  shells push them into the mobile drawer footer automatically.
- `fixed` pins the bar to the top via `position: fixed top-0 z-40`.
  Compose with `padding-top` on the page body to avoid content jumping
  under it.
- The mobile menu is built on the `Drawer` component — see the
  `Overlays/Drawer` stories for its standalone behavior.
