# TextList

## Overview

Token-driven `<ul>` and `<ol>` with the LifeSG body typography scale.
Two exports: `UnorderedList` (custom bullets supported as a React node)
and `OrderedList` (custom counter type + separator).

## Import

<Source
  language="tsx"
  code={`import { UnorderedList, OrderedList } from "@/components/ui/text-list";`}

## OrderedList

### Decimal

`counterType="decimal"` numbers items 1, 2, 3 — the default choice for
step-by-step instructions.

<Canvas of={TextListStories.OrderedDecimal} />

### Lower alpha

`counterType="lower-alpha"` counts a, b, c. Use for option lists and
sub-clauses where numbers are already taken by the parent list.

<Canvas of={TextListStories.OrderedAlpha} />

### Lower roman

`counterType="lower-roman"` counts i, ii, iii — the deepest level of
legal-style nesting, or anywhere a formal document convention calls
for roman numerals.

## Accessibility

- Both components render native `<ul>` / `<ol>` — assistive tech
  announces list semantics and item count automatically.
- Custom bullets and counters are wrapped with `aria-hidden` so the
  marker isn't read aloud; the list text is the only announced content.
- `OrderedList` keeps the native `reversed` / `start` attributes wired
  through, so they continue to drive both the visible numbering and the
  accessibility tree.

## Notes

- The `lower-alpha` counter wraps past `z` to `aa`, `ab`, … — matches
  CSS native `lower-latin` behaviour.
- Custom-bullet `UnorderedList` falls back to a flex layout
  (`list-none`, manual marker span) so the React node can be any size
  without breaking the indent.
- For inline lists (no marker, items on the same line), pair
  `bulletType="none"` with `className="flex gap-…"` rather than
  inventing another mode.
- Token namespace: typography tokens
  (`--typography-body-{bl|md|sm|xs}-{size|lh|ls}`) plus the
  font-family token.
