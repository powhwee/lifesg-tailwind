# Pagination

## Overview

Controlled page navigator with prev/next, optional first/last buttons,
ellipsis collapsing for long page lists, and an optional page-size
changer (built on `Select`).

## Import

<Source
  language="tsx"
  code={`import { Pagination } from "@/components/ui/pagination";

<Pagination
  totalItems={250}
  activePage={page}
  pageSize={10}
  onPageChange={setPage}
/>`}
/>

## Variants

### Few pages

Below the ellipsis threshold (9 pages), every page number renders
inline — nothing collapses. No configuration needed; this is purely a
function of `totalItems / pageSize`.

<Canvas of={PaginationStories.FewPages} />

### Many pages

Past the threshold, the page list collapses to `first / last / active
± 2` with ellipsis cells in between, keeping the control compact even
for hundreds of pages.

<Canvas of={PaginationStories.ManyPages} />

### Single page

With only one page of results, the control still renders (prev/next
disabled). Hide it at the consumer level if your UX prefers no chrome
for unpaginated lists.

<Canvas of={PaginationStories.SinglePage} />

## Optional UI

### First / last navigation

Pass `showFirstAndLastNav` to add jump-to-first / jump-to-last buttons
on the edges. Useful for long result sets where users need to reach the
ends quickly.

<Canvas of={PaginationStories.WithFirstLastNav} />

### Page-size changer

Pass `showPageSizeChanger` with `pageSizeOptions` to render a `Select`
beside the pager. Wire `onPageSizeChange` — it reports both the
adjusted page and the new size so the active page stays in range.

<Canvas of={PaginationStories.WithPageSizeChanger} />

## Accessibility

- The outer element is a `<nav aria-label="Pagination">` — assistive
  tech labels the whole region clearly.
- The active page has `aria-current="page"`.
- Prev/Next/First/Last buttons carry `aria-label`s ("Previous page" /
  etc.) so they're navigable without context.
- Ellipsis cells are visual-only (`select-none`, no semantic role) —
  screen readers skip past them.
- Disabled state on edge buttons uses native `disabled` so keyboard
  users can't tab through dead targets.

## Notes

- The ellipsis kicks in when `totalItems / pageSize > 9` pages; before
  that all pages render. The window is `first / last / active ± 2`.
- Pagination is fully controlled — pass `activePage`, `onPageChange`,
  and optionally `pageSize` / `onPageSizeChange`. Out-of-range
  `activePage` values are clamped silently.
- Page-size changer uses our `Select` component — it'll pick up the
  same theme + L3 tokens as the rest of the form chrome.
- Token namespace: `--pagination-*` (bg / border / hover bg / active
  bg & text / chevron text). Shares `--touch-target-default` for
  button sizing.
