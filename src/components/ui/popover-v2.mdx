# PopoverV2

LifeSG&rsquo;s v2 popover surface — a floating card that opens off a trigger
element. Compound exports:

- `PopoverV2` — the root card (`Box`-style component that consumers render
  inside a custom `popoverContent` render function)
- `PopoverV2.Trigger` — the high-level wrapper that owns the trigger
  element, the floating positioner, and click / hover open behaviour
- `PopoverV2.Inline` — a link-styled inline trigger with optional underline
  treatment and a trailing info icon, for inline use inside body text

## Accessibility

- The popover surface renders as `role="dialog"` with `aria-label` (default
  `"More information"`; override via `popoverAriaLabel`).
- `PopoverV2.Inline` puts `role="button"` and `aria-haspopup="dialog"` on
  the trigger span. When `content` is empty, an `aria-label` is required —
  fall back to `"More info"` if you don&rsquo;t set one.
- Focus management is delegated to Base UI&rsquo;s Popover primitive; click
  trigger opens via Enter / Space and closes via Escape.

## Notes

- The `popoverContent` render-function variant (LifeSG&rsquo;s shape for
  `enableResize`) is supported, but `enableResize` itself (auto-sizing to
  fit remaining viewport height) is deferred — set `maxHeight` + `overflow`
  on the `PopoverV2` root manually instead.
- Mobile takeover via `ModalV2` (LifeSG renders the popover full-screen on
  &lt; sm viewports) is also deferred — log a follow-up when first needed.
- All visual tokens live under `--popover-v2-*` in `overlays-tokens.css`.
