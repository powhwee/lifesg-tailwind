# FileUpload

## Overview

Drag-and-drop dropzone with a managed file list. Each row shows the file
name, MIME/size meta, optional thumbnail, optional inline progress bar, and
an optional inline error message. Supports drag-reordering via `@dnd-kit`
and editable image descriptions.

## Progress

Set `progress: 0–1` on a file item to show an inline progress bar in the
row. Hide the bar by omitting `progress` or setting it to `1`.

## Errors

`errorMessage` on a per-file basis renders a red row with the message
underneath. A top-level `errorMessage` prop renders a separate error
alert beneath the file list.

## Accessibility

- The visible upload trigger is a real `<button>`. The native file input is
  hidden but still triggered programmatically — `multiple`, `accept`, and
  `capture` are forwarded to it.
- Each progress bar exposes `role="progressbar"` with `aria-valuenow`.
- Each row's delete and drag-handle buttons get `aria-label="Remove {name}"`
  / `aria-label="Reorder {name}"`.
- The drag overlay surfaces are aria-hidden — the live region for screen
  readers comes from dnd-kit's announcements.

## Notes

- `@dnd-kit/core` + `@dnd-kit/sortable` are runtime dependencies — added in
  package.json alongside this port.
- The dashed dropzone container, padding, and corner radius come from shared
  `--file-container-*` tokens in `form-tokens.css` (also used by FileDownload).
- Like FileDownload, FileUpload is deliberately not wrapped in `<FormField>`
  — it bundles its own title/description and is a self-contained surface,
  matching LifeSG's decision to not expose `Form.FileUpload`.
