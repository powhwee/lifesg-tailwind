# MultiSelect

Multi-choice dropdown for picking zero-or-more options. The trigger
summarizes the current selection; the listbox is a checkbox list inside a
popover.

## Notes

- `maxSelectable` caps the count of selected options. Once reached, the
  unselected checkboxes are disabled.
- `formatSummary({ count, labels })` lets you customize the trigger label —
  e.g. "3 fruits selected" instead of the default comma-joined list.
- Reach for `FormMultiSelect` when you need the standard form-field layout.
