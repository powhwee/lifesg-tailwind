# Button

Primary call-to-action component. Supports six variants (`default`, `outline`,
`secondary`, `ghost`, `destructive`, `link`) and seven sizes including four
icon-only sizes.

## Accessibility

- Renders a native `<button>` by default; pair `aria-label` with `size="icon*"`
  when the button has no visible text.
- Disabled buttons set `aria-disabled` and skip focus.
- Focus ring uses `--lifesg-border-focus` via the component-radius token.
