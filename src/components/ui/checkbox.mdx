# Checkbox

## Overview

Single-selection input for binary or indeterminate boolean state. Two display
sizes; supports `checked`, `defaultChecked`, `indeterminate`, `disabled`, and
`aria-invalid`.

## Variants

### Checked

Pass `checked` (controlled) or `defaultChecked` (uncontrolled) to render the
box in its selected state. Use the controlled form when the value lives in
form state.

<Canvas of={CheckboxStories.Checked} />

### Indeterminate

`indeterminate` renders the mixed "dash" state. Use for a parent checkbox
whose children are partially selected (e.g. a "select all" header over a
list where only some rows are checked).

<Canvas of={CheckboxStories.Indeterminate} />

### Small size

`displaySize="small"` shrinks the box from 24 px to 16 px. Reach for it in
dense surfaces (table rows, compact filter panels) where the default size
crowds the layout.

## Accessibility

- Renders a native `<input type="checkbox">` via Base UI primitives; full
  keyboard support out of the box (Space toggles).
- Pair with a `<label htmlFor={id}>` so screen readers announce the control
  with its label.
- For `indeterminate`, the underlying input also gets `aria-checked="mixed"`.

## Notes

- Default size is `size-6` (24 px), small is `size-4` (16 px). These match
  LifeSG's *visible* SVG content, not their 32 / 24 px box-model. See
  `docs/parity-principle.md` "Selection-input indicator" for the rationale.
- Chrome renders via Lucide icons — see the
  [DESIGN-LANGUAGE divergence](?path=/docs/getting-started--docs) noted in
  the parity table.
