# DateRangeInput

## Overview

Paired DateInput for start + end dates. Both halves share one shell;
the Popover surfaces a `range` Calendar with start / middle / end
highlighting. Empty halves show "From" / "To" placeholders that
expand to segmented inputs on focus.

## Import

<Source
  language="tsx"
  code={`import {
  DateRangeInput,
  FormDateRangeInput,
} from "@/components/ui/date-range-input";

const [start, setStart] = React.useState("");
const [end, setEnd] = React.useState("");

<DateRangeInput
  value={start}
  valueEnd={end}
  onChange={(s, e) => { setStart(s); setEnd(e); }}
/>`}
/>

## Variants

### Pre-filled

Pass ISO strings as `value` and `valueEnd` to render both halves
populated, with the range highlighted in the popover calendar. Use when
editing an existing booking or filter rather than capturing a new one.

<Canvas of={Stories.PreFilled} />

### With min / max date

`minDate` and `maxDate` clamp both halves of the range — out-of-window
days are greyed out in the calendar. Note the segmented inputs still
accept any digits, so hard validation belongs upstream.

<Canvas of={Stories.WithMinMax} />

## States

### Error

Set `error` to render the red error border across the shared shell. The
bare component shows only the visual state — use `FormDateRangeInput`
for the standard message wiring.

<Canvas of={Stories.ErrorState} />

`disabled` greys out both halves and blocks the calendar popover.

## Composite (FormDateRangeInput)

### Form field

`FormDateRangeInput` wraps the input with the standard label +
description chrome and reserves the error slot so the layout doesn't
shift. Reach for it in forms instead of hand-rolling the wrapper.

## Accessibility

- Each segment carries an `aria-label` namespaced by side
  ("Start Day", "Start Month", "Start Year", and equivalents for
  "End"). Screen readers can land on any segment without ambiguity.
- Placeholder "From" / "To" buttons are real `<button>`s that focus
  the corresponding day input when activated — keyboard users get a
  clear entry point.
- An `ArrowRight` icon between the halves is `aria-hidden`; the
  semantic separation comes from the labels.
- Hidden `<input type="hidden" name="X-start" />` /
  `name="X-end"` mirrors the segmented values for form submit.

## Notes

- Calendar runs in `react-day-picker`'s `mode="range"` — selecting
  from + to in two clicks auto-closes the popover.
- Both halves stay in sync via `value` / `valueEnd`; the parent's
  `onChange` receives both on every edit (even when only one side
  changed).
- `minDate` / `maxDate` clamp both halves; the calendar greys out
  out-of-range dates and the segmented inputs accept any digits (so
  validation belongs upstream of `DateRangeInput`).
- Use `FormDateRangeInput` for the standard label + description + error
  wrapping. Composite uses `reserveErrorSlot` so the layout doesn't
  shift when the message appears.
