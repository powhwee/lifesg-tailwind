# DateNavigator

## Overview

Compact prev/next arrows with a clickable date label in the middle.
Useful for "today" headers on dashboards, week-view schedulers, or any
linear date scrubber. Optionally opens a Popover Calendar from the
date label.

## Import

<Source
  language="tsx"
  code={`import { DateNavigator } from "@/components/ui/date-navigator";

const [date, setDate] = React.useState("2026-05-27");

<DateNavigator
  selectedDate={date}
  onLeftArrowClick={setDate}
  onRightArrowClick={setDate}
  onCalendarDateSelect={setDate}
  view="day"
/>`}
/>

## Variants

### Short form

`showDateAsShortForm` abbreviates the month and day names ("Jan" /
"Mon" instead of "January" / "Monday"). Use in narrow headers where the
full label would wrap or truncate.

<Canvas of={Stories.ShortForm} />

### Show today

`showCurrentDateAsToday` appends ", Today" to the label when the
selected date matches the system date — a quick orientation cue for
dashboard headers.

<Canvas of={Stories.ShowToday} />

### Week view

`view="week"` steps by 7 days per arrow click and collapses the label
to a "DD Mon - DD Mon, YYYY" range. Use for week-based schedulers and
timetables.

## Constraints

### Clamped range

`minDate` / `maxDate` disable the prev / next arrows when the selected
date reaches the edge of the window, so users can't scrub out of range.

<Canvas of={Stories.ClampedRange} />

### Loading

`loading` disables both arrows while data for the new date is being
fetched — use it to prevent rapid-fire navigation from queueing stale
requests.

<Canvas of={Stories.LoadingState} />

## Accessibility

- Prev / Next buttons carry `aria-label="Previous"` / `"Next"` and
  use `disabled` natively when the date hits `minDate` / `maxDate`
  (or while `loading` is true).
- The centre label is a real `<button>` when a calendar picker is
  attached; otherwise it's a non-interactive `<span>`.
- Focus rings on all three interactive elements come from
  `--date-navigator-ring-focus` so keyboard users see a clear indicator.

## Notes

- `view="day"` steps by 1 day per click; `view="week"` steps by 7
  and the label collapses to "DD Mon - DD Mon, YYYY".
- `showCurrentDateAsToday` appends ", Today" to the day-view label
  when the selected date matches the system date.
- `showDateAsShortForm` switches month/day abbreviations from
  "January" / "Monday" to "Jan" / "Mon".
- Token namespaces: `--date-navigator-bg{,-hover}`,
  `--date-navigator-border`, `--date-navigator-text-date`,
  `--date-navigator-ring-focus`,
  `--date-navigator-date-min-width`. Buttons use the shared
  `--touch-target-compact` (40 px).
