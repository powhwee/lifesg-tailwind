# Divider

Horizontal rule with token-driven thickness, line style, and colour.
Defaults pull from `--divider-thickness`, `--divider-style`, and
`--divider-color`; per-call props override only what is passed.

## Accessibility

- Renders a native `<hr>`, which assistive tech announces as a separator.
- Decorative dividers inside a list or grid should set
  `aria-hidden="true"` on the wrapping element if they add no semantic
  break.

## Notes

- Token namespace: `--divider-*` (thickness / style / color). Override
  globally via `:root` or scope via a wrapping `[data-scope]`.
- Thickness is rendered through inline `style.borderTopWidth = var(--_divider-thickness)`
  (mirrored for `borderTopColor` and `borderTopStyle`). Earlier the
  component drove these through Tailwind arbitrary-value border-top
  utilities driven by CSS variables — that codegen path leaked the
  unresolved `var(…)` into the generated CSS, which Turbopack rejects
  as a parse error and `next build` only flags as a warning. Inline
  style sidesteps it.
- Accepts any CSS length via `thickness`, but stories cap the control
  at 1–8 px to match LifeSG usage.
