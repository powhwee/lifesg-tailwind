## Notes

- `allowClear` adds a clear-button slot when `value` is non-empty; call
  `onClear` to reset the controlled value.
- `aria-invalid="true"` flips the input to its error variant (red border,
  appropriate focus ring).
- Use `FormInput` when you want the standard label + description + error
  layout — it's the same input wrapped with the shared `FormField` slot.
