# Toggle

Card-style selection control that wraps a checkbox or radio behaviour in a
labeled, padded surface. Use for opinionated form choices where a plain
checkbox or radio would feel under-styled (e.g. "Select a delivery option").

## Notes

- `type` controls the underlying input ("checkbox", "radio", "yes", "no").
- `subLabel` adds a secondary description below the primary label.
- `compositeSection` renders content below the toggle card, revealed when the
  toggle is checked.
- Padding uses `--toggle-py / --toggle-px`; the card itself uses
  `rounded-component` (4 px) per the component-radius convention.
