# IconButton

## Overview

Square button containing a single icon. Three style types (`primary`,
`secondary`, `light`) and three size types (`large`, `default`,
`small`). Wraps Base UI's `Button` primitive — accepts the usual
`disabled` / `onClick` / `aria-*` props.

`default` and `small` map to the shared `--touch-target-*` tokens
(48 / 40 px) so the icon hit-target matches every other interactive
control in the system. `large` is a one-off 64 px square for hero
actions.

## States

### Destructive

There is no built-in destructive style type — colour the icon itself
(e.g. `text-lifesg-text-error` on the glyph) on a `secondary` button to
signal a delete action.

### Disabled

`disabled` swaps in the disabled tokens and blocks pointer events across

## Accessibility

- `aria-label` is **mandatory** — icon buttons have no visible text, so
  screen readers need an explicit name.
- Disabled state sets `pointer-events: none` and swaps the disabled
  tokens; the underlying button still reports `disabled` to assistive
  tech.
- Focus ring uses `--icon-button-ring-focus` and is visible on keyboard
  focus only (`focus-visible`).

## Notes

- Icon sizing is automatic via `[&_svg:not([class*='size-'])]:size-N`:
  large→7, default→5, small→4. Override per call by passing a `size-*`
  class on the icon if you need a different glyph size.
- Token namespaces: `--icon-button-bg-*`, `--icon-button-text-*`,
  `--icon-button-border-*`, `--icon-button-ring-focus`, plus
  `--touch-target-*` for sizing.
- For an icon inside a regular button (with a text label), use
  `<Button size="icon">` from `button.tsx` instead.
