# Textarea

## Overview

Multiline text input. Shares the LifeSG `--input-*` token system with
`Input`, plus an optional character counter for length-limited fields.
Exposes two exports: raw `Textarea` and a `FormTextarea` composite that
embeds it in `FormField`.

## Variants

### With counter

Pair `showCounter` with `maxLength` to render a live "N characters left"
row below the control. Use for length-limited fields (feedback boxes,
SMS-style messages) where users benefit from seeing the remaining budget.

<Canvas of={TextareaStories.WithCounter} />

### Disabled

`disabled` greys out the control and removes it from the tab order. Use
when the field is not applicable in the current context.

<Canvas of={TextareaStories.Disabled} />

### Read-only

`readOnly` shows a previously submitted value without allowing edits, but
keeps the control focusable so users can select and copy the text.

<Canvas of={TextareaStories.ReadOnly} />

### Error state

`aria-invalid="true"` switches the border and focus ring to the error
tokens. Pair with a visible error message (see `FormTextarea` below) so
the failure is announced, not just shown.

<Canvas of={TextareaStories.ErrorState} />

## Composite (FormTextarea)

### With label and description

`FormTextarea` wraps the control in `FormField`, wiring up the label and
optional description with the right `id` / `aria-describedby` plumbing.
Prefer it over hand-rolling labels around the raw `Textarea`.

<Canvas of={TextareaStories.CompositeFormField} />

### With error message

Pass `errorMessage` together with `aria-invalid="true"` to show the
validation failure below the field and announce it to screen readers.

## Accessibility

- `aria-invalid="true"` triggers the error border + ring tokens. Pair
  it with a visible message via `FormTextarea`'s `errorMessage` so screen
  readers actually hear what is wrong.
- The counter ("N characters left") is decorative — it sits outside the
  control and is not announced. For length-critical fields, surface the
  same information in the description or error message.
- `readOnly` keeps the control focusable so users can copy the text;
  `disabled` removes it from the tab order entirely.

## Notes

- `showCounter` requires `maxLength` — without an upper bound there's
  nothing to count down from. The component silently ignores
  `showCounter` if `maxLength` is missing.
- `resize-y` is built in so users can drag the bottom edge but not the
  width — keeps the layout stable inside a fixed-width column.
- Token namespace: shared `--input-*` plus `--input-counter-text` for
  the counter row.
