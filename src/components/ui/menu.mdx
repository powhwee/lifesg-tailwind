# Menu

## Overview

Dropdown menu built on Base UI's `Menu`. Supports plain items, link
items, checkbox items, radio groups, separators, group labels, and
submenus.

## Import

<Source
  language="tsx"
  code={`import {
  Menu,
  MenuTrigger,
  MenuContent,
  MenuItem,
  MenuCheckboxItem,
  MenuRadioGroup,
  MenuRadioItem,
  MenuGroup,
  MenuGroupLabel,
  MenuSeparator,
  MenuSubmenu,
  MenuSubmenuTrigger,
  MenuLinkItem,
} from "@/components/ui/menu";

<Menu>
  <MenuTrigger render={<Button>Open</Button>} />
  <MenuContent>
    <MenuItem onClick={…}>Action</MenuItem>
  </MenuContent>
</Menu>`}
/>

## With groups

Wrap related items in `MenuGroup` with a `MenuGroupLabel`, separated by
`MenuSeparator`. Use when a menu mixes different kinds of actions (e.g.
recent files vs. commands) and a flat list would be hard to scan.

<Canvas of={MenuStories.WithGroups} />

## Checkbox items

`MenuCheckboxItem` is a controlled boolean toggle (`checked` /
`onCheckedChange`) with a built-in checkmark. Use for independent
on/off settings like text formatting flags.

<Canvas of={MenuStories.CheckboxItems} />

## Radio group

`MenuRadioItem`s inside a `MenuRadioGroup` (`value` / `onValueChange`)
give an exclusive choice with a built-in dot indicator. Use when
exactly one option can be active, such as a theme picker.

<Canvas of={MenuStories.RadioGroup} />

## Submenu

`MenuSubmenu` with a `MenuSubmenuTrigger` nests a second `MenuContent`
that opens to the side. Use sparingly — one level of nesting for
variants of the same action (e.g. "Export to…").

<Canvas of={MenuStories.Submenu} />

## Link items

`MenuLinkItem` renders a real `<a>`, so it gets announced as a link and
supports `href` / `target` natively. Use for navigation; keep
`MenuItem` with `onClick` for JS-handled actions.

<Canvas of={MenuStories.LinkItems} />

## Disabled items

Pass `disabled` to keep an action visible but inert — useful when the
action exists but its precondition isn't met (no selection, no
recents). Disabled items are skipped by keyboard navigation.

<Canvas of={MenuStories.DisabledItems} />

## Accessibility

- Base UI wires the trigger and popup with `aria-haspopup`,
  `aria-expanded`, `aria-controls`, plus keyboard navigation
  (Arrow keys, Home/End, type-to-select).
- Checkbox items expose `aria-checked` correctly with `true` /
  `false`; radio items report `aria-checked` per group.
- `MenuLinkItem` is a real `<a>` so screen readers announce it as a
  link rather than a menu item — pick `MenuItem` (with `onClick`) for
  in-app navigation handled by JS.
- Submenu trigger sets `aria-haspopup="menu"` and supports keyboard
  open (right arrow) and close (left arrow).

## Notes

- Token namespaces: `--popover-*` (shared shell tokens — border, bg,
  shadow, radius). Items use `--lifesg-bg-hover` for highlight.
- Use `MenuCheckboxItem` for boolean toggles, `MenuRadioItem` inside a
  `MenuRadioGroup` for exclusive choices. Don't manually wire the
  checkmark / dot — both are rendered by the component.
- Submenu can re-use `MenuContent` so the visual styling stays
  consistent.
- For a single button-triggered popover with arbitrary content (not
  list items), use `popover` instead.
