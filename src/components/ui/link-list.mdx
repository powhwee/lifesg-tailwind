# LinkList

## Overview

Vertical list of in-page anchors with title, optional description, and
chevron affordance. Supports a "View more / View less" toggle when
`maxShown` is fewer than the items.

## Import

<Source
  language="tsx"
  code={`import { LinkList } from "@/components/ui/link-list";

<LinkList
  items={[
    { title: "Apply for HDB BTO flat", description: "…", href: "/bto" },
    { title: "Renew CPF nomination", description: "…", href: "/cpf" },
  ]}
  style="default"
  maxShown={3}
/>`}
/>

## Variants

### Small

`style="small"` drops the title and description to the compact text
scale. Use inside denser surfaces (cards, side panels) where the
default scale would dominate.

<Canvas of={LinkListStories.Small} />

### Title only

Omit `description` on the items and each row collapses to just the
title and chevron. Use when the link titles are self-explanatory and
extra copy would be noise.

<Canvas of={LinkListStories.TitleOnly} />

### With secondary description

Pass `secondaryDescription` for a second, subtler line under the
description — good for metadata like "Updated this week" that
shouldn't compete with the main copy.

<Canvas of={LinkListStories.WithSecondaryDescription} />

## Expandable

When `maxShown` is fewer than the number of items, the list truncates
and renders a "View more / View less" toggle. Use for long task lists
where you want the first few links visible without a wall of rows.

<Canvas of={LinkListStories.ExpandableViewMore} />

## Accessibility

- Each item is a real `<a>` so assistive tech announces "link". Pass
  `target="_blank" rel="noopener"` for external links per usual.
- Chevron + plus / minus icons are `aria-hidden` decoration.
- The "View more / less" button is a real `<button>`. It doesn't carry
  `aria-controls` to the hidden items, but the visible/hidden state
  reflows naturally and the button label updates each toggle.

## Notes

- `style` toggles the title + description text scale
  (`--link-list-title-default` / `-small`,
  `--link-list-desc-default` / `-small`).
- `maxShown` is ignored if it's `>=` the items length — no toggle
  appears.
- Token namespaces: `--link-list-link`, `--link-list-border`, plus the
  title/desc size tokens above.
- For *external* navigation lists (footer links, sitemaps), reach for
  `Footer` or a plain `<ul>` — LinkList is calibrated for primary
  page-content link affordances.
