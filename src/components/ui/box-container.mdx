# BoxContainer

## Overview

A titled section that collapses on click. Built on Base UI's
`Collapsible`. Supports `error` / `warning` display states, a
call-to-action slot in the header, and a fully static (non-collapsible)
mode.

## Import

<Source
  language="tsx"
  code={`import { BoxContainer } from "@/components/ui/box-container";

<BoxContainer title="Section title" defaultExpanded>
  Section body…
</BoxContainer>`}
/>

## Display states

### Error

`displayState="error"` adds an error icon to the header. Use when the
collapsed section contains failed validation the user must fix —
typically paired with a collapsed-by-default section so the icon draws
the user in.

<Canvas of={BoxContainerStories.ErrorState} />

### Warning

`displayState="warning"` adds a warning icon instead. Use for
non-blocking issues — something inside needs attention but doesn't stop
submission.

<Canvas of={BoxContainerStories.WarningState} />

## Accessibility

- The collapse trigger is a real `<button>` and reports
  `aria-expanded` via Base UI's `Collapsible.Trigger`.
- The panel is kept mounted (`keepMounted`) so focus inside the panel
  is preserved across toggles and inline form state doesn't reset.
- State icons (`error` / `warning`) are decorative (`aria-hidden`) — the
  state should also be conveyed in the body text or surrounding
  validation summary.
- Focus ring on the trigger is inset (`outline-offset: -2px`) so the
  rounded border isn't broken by the focus indicator.

## Notes

- Token namespace: `--box-container-*` (bg, border, padding-x,
  header-y, body-y, icon-error, icon-warning).
- Pass either `expanded` (controlled) or `defaultExpanded`
  (uncontrolled). Don't mix them on the same instance.
- Animated height uses `h-collapsible-panel-height` — that arbitrary
  utility reads Base UI's runtime variable, not a design token, so it
  stays as an arbitrary-value class rather than being promoted into the
  token namespace.
