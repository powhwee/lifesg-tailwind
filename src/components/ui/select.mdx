# Select

Single-choice dropdown for picking one option from a list. Built on
`@base-ui/react/select`. Reach for `FormSelect` when you need the standard
form-field layout (label + description + error).

## Accessibility

- Listbox keyboard nav: Up / Down to move, Enter / Space to commit,
  Escape to close.
- Type-ahead: hitting a letter jumps to the next option starting with that
  letter.
- `aria-expanded` and `aria-controls` wire the trigger to the listbox.
