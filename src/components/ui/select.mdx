# Select

## Overview

Single-choice dropdown for picking one option from a list. Built on
`@base-ui/react/select`. Reach for `FormSelect` when you need the standard
form-field layout (label + description + error).

## Import

<Source
  language="tsx"
  code={`import { Select, FormSelect } from "@/components/ui/select";`}
/>

## Variants

### Disabled

`disabled` greys out the trigger and prevents the listbox from opening.
Use when the choice depends on an earlier answer that has not been given
yet.

<Canvas of={SelectStories.Disabled} />

### Error state

`error` flips the trigger chrome to the error border and ring tokens.
Pair with a visible message via `FormSelect`'s `errorMessage` so the
failure is announced, not just shown.

<Canvas of={SelectStories.ErrorState} />

## Accessibility

- Listbox keyboard nav: Up / Down to move, Enter / Space to commit,
  Escape to close.
- Type-ahead: hitting a letter jumps to the next option starting with that
  letter.
- `aria-expanded` and `aria-controls` wire the trigger to the listbox.
