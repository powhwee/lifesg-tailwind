# Layout

## Overview

Page-layout primitives — `Section`, `Container`, `Content`, `ColDiv` —
that map LifeSG's grid system onto CSS Grid and Flexbox via design
tokens.

## Accessibility

- `Section` renders a native `<section>` — give it an accessible name
  via `aria-label` or `aria-labelledby` when the page has multiple
  sections; otherwise screen readers cannot distinguish them.
- `ColDiv` is a pure `<div>` and adds no semantics; the surrounding
  `Container` / `Section` carries the semantic role.

## Notes

- Token namespaces: `--layout-container-max`, `--layout-container-pad`,
  `--layout-grid-columns`, `--layout-grid-gutter`. The column count and
  gutter switch automatically at LifeSG breakpoints.
- `ColDiv` uses CSS variables (`--coldiv-xxs`, `--coldiv-xs`, …,
  `--coldiv-xxl`) consumed by media queries in `globals.css`. Unset
  breakpoints inherit the fallback so partial configs Just Work.
- `ColDiv` defaults to `grid-column: 1 / -1` (spans every column) at
  every breakpoint when no `*Cols` prop is set — bare siblings will
  overlap as full-width rows rather than dividing the grid. Pass at
  least `xxsCols={N}` to opt into per-column placement.
- For one-off non-grid layouts inside a `Section`, drop the
  `Container` / `Content` wrappers and use raw flex/grid utilities.
