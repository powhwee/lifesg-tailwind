# Shadow

Four intensity tiers (`xs` / `sm` / `md` / `lg`) × two opacities
(`subtle`, `strong`) plus contextual variants (`focus`, `error`).

## Default

<Canvas of={ShadowStories.Default} />

## Component aliases

Components don't reference the L1 shadows directly — they go through L3
component aliases so global swaps are possible:

| Component | Token |
|-----------|-------|
| Card | `--card-shadow` |
| Modal box (v1 + v2) | `--modal-box-shadow` |
| Popover | `--popover-shadow` |
| Drawer | `--drawer-shadow` |

## Usage

<Source
  language="tsx"
  code={`/* Preferred — component-owned alias. */
<div className="shadow-card-shadow" />
<div className="shadow-popover-shadow" />

/* L1 raw — only when adding a new chrome surface that needs a shadow. */
<div style={{ boxShadow: "var(--lifesg-shadow-sm-subtle)" }} />`}
/>

## Notes

- All shadows derive from neutral `#686868` blended at 24% (subtle) or
  50% (strong). Focus and error variants swap the colour to
  `--lifesg-primary-60` and a red equivalent respectively.
- For new chrome that needs a shadow, **add a `--component-shadow`
  alias** in the relevant L3 token file before using it directly —
  keeps the shadow editable per surface.
- Token namespace: `src/app/lifesg-tokens.css` for the raw scale.
