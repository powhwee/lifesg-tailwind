# Shadow

Three intensity tiers (`xs` / `sm` / `md`) × two opacities (`subtle`,
`strong`) plus contextual variants (`focus`, `error`).

## Component aliases

Components don't reference the L1 shadows directly — they go through L3
component aliases so global swaps are possible.

| Component | Token |
|-----------|-------|
| Card      | `--card-shadow` |
| Modal box (v1 + v2) | `--modal-box-shadow` |
| Popover   | `--popover-shadow` |
| Drawer    | `--drawer-shadow` |

<Source
  language="tsx"
  code={`<div className="shadow-card-shadow" />
<div className="shadow-popover-shadow" />`}
/>

## Notes

- All shadows derive from neutral `#686868` blended at 24% (subtle) or
  50% (strong). Focus + error variants swap the colour to
  `--lifesg-primary-60` / a red equivalent.
- For new chrome that needs a shadow, add a `--component-shadow`
  alias in the relevant L3 token file before using it — keeps the
  shadow editable per surface.
