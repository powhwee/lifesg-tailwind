## Semantic L2 aliases

The aliases below sit on top of the ramps and are what components
actually reference. Override at L2 to change the visual language
without retuning every component.

### Backgrounds

<div style={{ display: "grid", gridTemplateColumns: "repeat(4, minmax(0, 1fr))", gap: 12 }}>
  <ColorSwatch token="--lifesg-bg" />
  <ColorSwatch token="--lifesg-bg-subtle" />
  <ColorSwatch token="--lifesg-bg-strong" />
  <ColorSwatch token="--lifesg-bg-inverse" />
  <ColorSwatch token="--lifesg-bg-primary" />
  <ColorSwatch token="--lifesg-bg-hover" />
  <ColorSwatch token="--lifesg-bg-selected" />
  <ColorSwatch token="--lifesg-bg-error" />
</div>

### Text (shown on white)

<div style={{ display: "grid", gridTemplateColumns: "repeat(4, minmax(0, 1fr))", gap: 12, padding: 16, backgroundColor: "white" }}>
  {[
    "--lifesg-text",
    "--lifesg-text-subtle",
    "--lifesg-text-strong",
    "--lifesg-text-primary",
    "--lifesg-text-error",
    "--lifesg-text-success",
    "--lifesg-text-warning",
    "--lifesg-text-disabled",
  ].map((t) => (
    <div key={t}>
      <div style={{ color: `var(${t})`, fontSize: 18, fontWeight: 600 }}>Aa</div>
      <code style={{ fontSize: 11, fontFamily: "var(--font-mono)" }}>{t}</code>
    </div>
  ))}
</div>

### Borders

<div style={{ display: "grid", gridTemplateColumns: "repeat(4, minmax(0, 1fr))", gap: 12 }}>
  {[
    "--lifesg-border",
    "--lifesg-border-subtle",
    "--lifesg-border-strong",
    "--lifesg-border-focus",
    "--lifesg-border-error",
    "--lifesg-border-success",
  ].map((t) => (
    <div key={t}>
      <div
        style={{
          height: 56,
          border: `2px solid var(${t})`,
          borderRadius: 4,
          backgroundColor: "white",
        }}
        aria-hidden
      />
      <code style={{ fontSize: 11, fontFamily: "var(--font-mono)" }}>{t}</code>
    </div>
  ))}
</div>

## Usage

<Source
  language="tsx"
  code={`/* Prefer semantic L2 aliases in component code. */
<div className="bg-lifesg-bg text-lifesg-text border border-lifesg-border" />

/* Drop down to L1 ramps only when L2 doesn't cover the case. */
<div style={{ background: "var(--lifesg-primary-60)" }} />`}
/>
