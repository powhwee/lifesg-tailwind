## Decisions made under ambiguity

The plan flagged two open questions; I committed to the
plan-recommended approach for both since you weren't around to answer:

1. **Singpass logo SVG**: inlined the path data as React components in
   `singpass-button.tsx` rather than fetching from `assets.life.gov.sg`.
   Trade-off: offline-robust and no extra network request, but the SVG path
   data is large (~6 KB of literal string). Stored as three `const`
   variables in the same file so the diff stays readable.
2. **PredictiveTextInput composition**: wrapped our `<Input>` with an
   absolutely-positioned dropdown sibling, manual ARIA combobox keyboard
   handling. Did NOT use Base UI's `Popover` for the dropdown —
   combobox is the standard pattern for this and using Popover would mean
   wiring a hidden trigger element which adds noise.

Decisions on the "User Review Required" boxes from the plan — all matched
the plan's stated approach (token names derived during impl, @dnd-kit
deps added, modal v1 left alone, FormPredictiveTextInput yes/Form.FileX no).

## Conventions established this session

| Convention | Where | Rationale |
|------------|-------|-----------|
| `parameters: { controls: { disable: true } }` on every story whose `render` takes no args | `src/components/ui/*.stories.tsx` | Per the misleading-controls-panel finding in `2026-05-27-handover.md` |
| Component-specific `data-testid` inside the side-by-side panes | `<div data-testid="form-file-upload-ours">` etc. | Plan §verification — keeps each comparison panel addressable by Playwright |
| Compound `Object.assign(Root, { Trigger, Inline, … })` for new compound components | popover-v2.tsx, singpass-button.tsx | Mirrors LifeSG's `SingpassButton.Default` / `ModalV2.Card` shape — sub-components import together from a single entry |
| FileUpload / FileDownload ship **without** FormField wrappers | (no `FormFileUpload` etc. export) | LifeSG's `Form` namespace doesn't expose them either; they bundle their own title / description and are self-contained surfaces |
| Inline SVG path data for brand assets that LifeSG fetches from a CDN | `singpass-button.tsx` `singpassLogoPath` consts | Offline-robust, no extra network request, no external dependency on `assets.life.gov.sg` |
